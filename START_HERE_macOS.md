# ✨ НАЧНИТЕ ЗДЕСЬ - macOS (zsh)

## 🎯 Самый простой способ запуска

У вас macOS с zsh (современная версия) - это нормально! Все будет работать.

---

## 📋 ШАГ 1: Откройте Terminal

1. Нажмите `Cmd + Пробел` (Spotlight)
2. Введите: `Terminal`
3. Нажмите Enter

Откроется терминал с `%` в конце строки (это zsh).

---

## 📋 ШАГ 2: Перейдите в папку проекта

Скопируйте и вставьте эту команду в терминал:

```bash
cd ~/Desktop/telegram-summarizer-bot
```

Нажмите Enter.

Вы должны увидеть что-то вроде:
```
telegram-summarizer-bot %
```

---

## 📋 ШАГ 3: Запустите установку

Скопируйте и вставьте:

```bash
./setup.sh
```

Нажмите Enter.

Вы увидите:
```
🚀 Установка Telegram Summarizer Bot
======================================

📋 Проверка Python...
✅ Python найден: Python 3.11.x
...
```

⏱️ Установка займет 2-3 минуты. Подождите пока не появится:
```
✅ Установка завершена успешно!
🎉 Бот готов к запуску!
```

---

## 📋 ШАГ 4: Запустите бота

Скопируйте и вставьте:

```bash
./run.sh
```

Нажмите Enter.

Вы увидите:
```
🚀 Запуск Telegram Summarizer Bot
====================================

⚡ Активация виртуального окружения...

🤖 Запуск бота...
Для остановки нажмите Ctrl+C

====================================

2026-01-14 18:20:00 - INFO - 🚀 Бот успешно запущен и готов к работе!
```

✅ **БОТ РАБОТАЕТ!**

---

## 📋 ШАГ 5: Протестируйте в Telegram

1. Откройте Telegram (на телефоне или в браузере)
2. Найдите вашего бота в поиске
3. Нажмите `/start`
4. Отправьте тестовую ссылку:
   ```
   https://en.wikipedia.org/wiki/Artificial_intelligence
   ```
5. Подождите 10-15 секунд
6. Получите краткое содержание! 🎉

---

## 🛑 Остановка бота

В терминале нажмите: **Ctrl + C**

Бот остановится.

---

## 🔄 Запуск в следующий раз

Когда захотите снова запустить бота:

```bash
cd ~/Desktop/telegram-summarizer-bot
./run.sh
```

Всего 2 команды!

---

## ⚠️ Если что-то пошло не так

### Python не найден

Установите Python:
```bash
# Если есть Homebrew
brew install python3

# Или скачайте с python.org
open https://www.python.org/downloads/
```

### "Permission denied" при ./setup.sh

Выполните:
```bash
chmod +x setup.sh run.sh
./setup.sh
```

### Ошибка "command not found: pip"

Установите pip:
```bash
python3 -m ensurepip --upgrade
```

### Бот запустился, но не отвечает в Telegram

1. Проверьте, что терминал все еще открыт и бот работает
2. Проверьте токен в файле `.env`
3. Проверьте интернет-соединение

## 💡 Полезные советы

### Терминал всегда должен быть открыт
Пока бот работает, терминал должен оставаться открытым. Закроете - бот остановится.

### Логи
Все логи сохраняются в файл `bot.log` - можете посмотреть что происходит.

### Для работы 24/7
Если хотите чтобы бот работал постоянно без компьютера - используйте деплой на Render.com (инструкция в README.md).
