# ⚠️ Конфликт деплоя - Бот уже запущен на хостинге

## 🔴 Проблема

Бот получает ошибку **409 Conflict**:
```
Conflict: terminated by other getUpdates request; 
make sure that only one bot instance is running
```

## 🎯 Причина

Бот уже **запущен на облачном хостинге** (Render.com или Railway). Telegram API позволяет только **одному инстансу** бота получать обновления через метод `getUpdates`.

Когда вы пытаетесь запустить бота локально, оба инстанса (локальный и облачный) пытаются получать обновления → конфликт.

## ✅ Решения

### Вариант 1: Использовать бота на хостинге (Рекомендуется)

**Бот УЖЕ РАБОТАЕТ на хостинге!**

Просто используйте его:
1. Откройте Telegram
2. Найдите бота: `@url_sum_bot` (или ваше имя)
3. Отправьте `/start`
4. Отправьте ссылку на статью

**Преимущества:**
- ✅ Работает 24/7
- ✅ Не нужно держать компьютер включенным
- ✅ Бесплатно (Render.com дает 750 часов/месяц)

### Вариант 2: Остановить бота на хостинге для локального тестирования

#### Если бот на Render.com:

1. Зайдите на https://dashboard.render.com/
2. Найдите ваш сервис с ботом
3. Нажмите **"Suspend"** или **"Delete"**
4. Подождите 1-2 минуты
5. Запустите локально:
```bash
python3 main.py
```

#### Если бот на Railway:

1. Зайдите на https://railway.app/
2. Найдите проект с ботом
3. Удалите деплой или остановите сервис
4. Запустите локально

---

### Вариант 3: Создать второго бота для локального тестирования

1. Откройте Telegram → найдите **@BotFather**
2. Отправьте `/newbot`
3. Придумайте имя и username
4. Получите новый токен
5. Создайте файл `.env.local`:
```bash
# .env.local
TELEGRAM_BOT_TOKEN=ваш_новый_токен_здесь
HUGGINGFACE_TOKEN=ваш_hf_токен_здесь
DEEPSEEK_API_KEY=ваш_deepseek_ключ_здесь
```
6. Запустите с новым токеном:
```bash
python3 -c "
import os
from dotenv import load_dotenv
load_dotenv('.env.local')
exec(open('main.py').read())
"
```

1. Зайдите на Render Dashboard
2. Выберите сервис с ботом
